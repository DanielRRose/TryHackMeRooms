## Using the write-ups

The write-ups may include investigation steps, commands, room questions, and
answers. Try the room yourself before consulting the answers if you want to
use these notes as a learning resource.

All hands-on activity described here is intended for the authorized TryHackMe
lab environment. Follow TryHackMe's rules and do not use lab techniques or
indicators against systems without permission.
